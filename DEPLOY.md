# Update the existing GitHub portfolio

Extract the ZIP and copy its contents into the root of the existing `jaredtanksley/aboutme` repository.

Replace/add these paths:

- `index.html`
- `css/styles.css`
- `js/site.js`
- `images/` (including `jared-headshot.png`, `osu-logo.png` and existing imagery)
- `favicon.ico`
- `jared-tanksley-resume.pdf`

Keep these folders and filenames intact; relative URLs support the `/aboutme/` path.
Commit the changes to the branch used by the existing GitHub Pages deployment. No build step is required. After deployment, refresh the page to load the new version.

The downloadable resume is the exact, unmodified new resume supplied for this update.
